# SEO Implementation Plan

> **For Claude:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** Add comprehensive SEO to Kanojo Studio — metadata, sitemap, robots.txt, structured data, and image alt fixes — to rank for AI portrait generator keywords.

**Architecture:** Next.js Metadata API throughout. Static files for sitemap/robots. JSON-LD script tag on landing page. Client-only pages get metadata via a wrapper `layout.tsx` since `metadata` can't be exported from `'use client'` files.

**Tech Stack:** Next.js 16 App Router Metadata API, JSON-LD

import type { MetadataRoute } from 'next'

export default function sitemap(): MetadataRoute.Sitemap {
  return [
    {
      url: 'https://kanojostudio.com',
      lastModified: new Date(),
      changeFrequency: 'weekly',
      priority: 1,

### Task 9: JSON-LD structured data on landing page

**Files:**
- Modify: `app/page.tsx`

**Step 1: Add JSON-LD script to the page JSX**

Add a `<script>` tag at the top of the returned JSX:

```tsx
const jsonLd = {
  '@context': 'https://schema.org',
  '@graph': [
    {
      '@type': 'WebSite',
      '@id': 'https://kanojostudio.com/#website',
      url: 'https://kanojostudio.com',
      name: 'Kanojo Studio',
      description: 'AI-powered portrait photography platform',
      potentialAction: {
        '@type': 'SearchAction',
        target: {
          '@type': 'EntryPoint',
          urlTemplate: 'https://kanojostudio.com/community?q={search_term_string}',
        },
        'query-input': 'required name=search_term_string',
      },
    },
    {
      '@type': 'Organization',
      '@id': 'https://kanojostudio.com/#organization',
      name: 'Kanojo Studio',
      url: 'https://kanojostudio.com',
      logo: {
        '@type': 'ImageObject',
        url: 'https://kanojostudio.com/logo.svg',
      },
    },
  ],
}

return (
  <>
    <script
      type="application/ld+json"
      dangerouslySetInnerHTML={{ __html: JSON.stringify(jsonLd) }}
    />
    <div className="flex flex-col gap-24">
      {/* ... existing sections ... */}
    </div>
  </>
)
```
